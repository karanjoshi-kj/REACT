REACT HOOKS ==> 
PERFORMES SOME APPROPRIATE TASK TO HOLD STATES OR LIFE CYCLE OF THE COMPONENT
PERFORMES TASKS LIKE => 
1. HOLDS STATE OR MULTIPLE STATE
2. PROPER-RENDERING 
3. API-FETCH 


STATE : WHAT THE FUNCTION DOING OR WHAT IS THE VALUE OF VARIABLE PROPERTY =>
 i. image -> color , size
 ii. variable -> vlaue 
 iii. function -> what 


 TYPES OF REACT HOOKS => 
1. useState 
2. useEffect
3. useContext
4. useCallback 
5. useMemroy



1. useState ==> 
THIS STATE OF REACT HOOKS IS SPECIALLY USED TO MAINTAIN THE STATE OF A VARIABLE , FUNCTION , OBJECT , STRING , ARRAY .

SYNTAX : 
const[state , updated state or setstate]  = useState(initial value)

HERE => 
1. state -> value at a point of time .
2. setstate -> function which is updating the value of the state .
